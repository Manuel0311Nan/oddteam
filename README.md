# OddTeam

Equipos Pokémon aleatorios pero **válidos para la historia** de una versión concreta del juego, para no jugar siempre con los mismos.

- Qué es y cómo se trabaja: [`CLAUDE.md`](CLAUDE.md)
- Especificación: [`specs/`](specs/README.md)
- Plan y estado: [`specs/09-plan-de-ejecucion.md`](specs/09-plan-de-ejecucion.md)

## Desarrollo

Requisitos: Node 20+ y pnpm 10.

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm check      # lint + typecheck + test
```

Proyecto de fans sin afiliación con Nintendo, Game Freak, Creatures ni The Pokémon Company. Datos de [PokéAPI](https://pokeapi.co).
